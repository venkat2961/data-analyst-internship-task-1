# Data Analyst Internship – Task 1

## Data Cleaning and Preprocessing

This project demonstrates data cleaning and preprocessing using Python and Pandas.

## Dataset

Sales Dataset containing 1,000 records.

## Cleaning Performed

- Removed unnecessary index column
- Standardized column names
- Cleaned text values
- Converted date column
- Checked missing values
- Checked duplicate records
- Converted numeric columns
- Validated Total Amount
- Exported cleaned dataset

## Tools Used

- Python
- Pandas
- VS Code
- Excel

## Files

### Sales_Dataset.csv
Original dataset.

### cleaning.py
Python script used for data cleaning and preprocessing.

### Cleaned_Sales_Dataset.csv
Final cleaned dataset.

## Result

The final dataset contains 1,000 clean records and is ready for further analysis.
